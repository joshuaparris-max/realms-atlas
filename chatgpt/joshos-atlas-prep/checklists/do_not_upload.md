# Do Not Upload / Do Not Commit

Do not upload or commit:

- `.env`
- API keys
- GitHub PATs
- Vercel tokens
- OpenAI / Anthropic / OpenRouter / Groq keys
- Firebase/Supabase service keys
- health records
- child therapy documents
- NDIS plans
- school/student/staff data
- bank statements
- private family/marriage notes
- tenancy evidence photos unless deliberately redacted
- raw private emails
- raw Gmail exports
- raw Google Drive private folders
