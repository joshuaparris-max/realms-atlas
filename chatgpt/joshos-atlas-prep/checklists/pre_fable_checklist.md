# Pre-Fable Checklist

Before running Fable:

- [ ] Security scans run
- [ ] `00_SECURITY_PRECHECK.md` filled
- [ ] No raw secrets included
- [ ] No raw child/health/school/family docs included
- [ ] Source register complete enough
- [ ] Source cards created
- [ ] Low-confidence cards excluded or approved manually
- [ ] `QUALITY_GATE.md` completed
- [ ] Architecture draft exists
- [ ] Schema draft exists
- [ ] First commit scope exists
- [ ] Stack constraints included
- [ ] Fable prompt ready
- [ ] `fable-output/` placeholder files exist
